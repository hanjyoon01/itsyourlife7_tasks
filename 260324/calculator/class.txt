    기능 구현
    -   계산기 UI에서 숫자 (operand), 사칙연산 (operator)
    -   입력된 데이터를 출력
    =>  입력 받은 값을 저장하는 데이터 정의
        필요한 부분을 바인딩 처리

    1. App.vue
        1-1 데이터(변수) 정의 
        - 출력데이터 저장                       => output
        - 이전에 입력된 숫자, 연산 결과 저장    => prev
        - 현재 입력 중인 숫자 저장              => cur
        - 사용자가 입력한 연산자 저장           => operator

        1-2 데이터 중 HTML 요소와 바인딩 데이터?
            사용자에게 계속 노출되는 데이터 => output => 양방향 데이터로 처리

        1-3 이벤트 연결
            계산기 UI에 필요한 이벤트를 연결
            output 버튼 제외 숫자 10개, . , 연산자 (+, -, *, /), C 버튼
            클릭 이벤트로 처리 (@click) 연결
            => 이벤트에 따른 핸들러 작성        => operation

    2.  계산기 로직 구현 (계산 작업/순서/조건 정의)
        operation() 함수 내부에 구현

        2-1 클릭한 버튼 값 가져오기
            <input> value 속성에 할당된 값을 가져온다.
            이벤트 객체가 가져와서 출력하는 코드 작성

        2-2 입력값 e.currentTarget.value => output
            이벤트가 발생한 UI 값을 출력칸에 노출되도록 구현
            =>  output 부분

        -   버튼 클릭 시 해당 숫자를 n 변수에 저장 (내부적으로 문자열 데이터)
        -   사용자가 입력한 숫자를 cur 데이터에 저장 (문자열 덧셈)
        -   cur 데이터를 output에 저장
        -   cur에 저장된 문자열을 output에 출력
